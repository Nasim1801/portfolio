# Engineering Lab V2 game fidelity review

Branch `codex/engineering-lab-v2` starts at production `ad2a9aa`. The two life demos sit within the existing V4 Engineering Lab. The homepage, case-study layouts, professional CV, Phase 2 evidence, Sumlume rules and Physio-AI implementation match the production baseline. The homepage hero also matched pixel for pixel at 390 and 1440 CSS px in matched captures.

## Original game review and asset provenance

**PathLife.** I read the available SwiftUI dashboard, theme, portrait and event-sheet components, and compared them with the published iOS dashboard and event artwork. The older SwiftUI checkout uses a portrait and balance in the player header, a dashboard of stats and history, event sheets and a bottom action area. The release captures show a blue player header, mint Age Up action and coloured decision buttons. The release captures informed the browser palette and placement. The exact released iOS build was unavailable for direct execution as part of this review. [PathLife App Store listing](https://apps.apple.com/gb/app/pathlife/id6769602618) · [PathLife Studio project page](https://www.pathlifestudio.com/pathlife.html)

**PawLife.** I inspected the original React Native Home screen, environment-stage composition, immediate care sheet and tactile care rules. The Home screen centres the companion in a room with a story hook and care actions. The native captures show Bella on a rug, and the care capture pairs a large character on a mint playfield with a warm, rounded action sheet. The browser uses those recognisable surfaces and its own care rules and feedback. [PawLife Studio project page](https://www.pathlifestudio.com/pawlife.html) · [Published PawLife case study](https://nasim1801.github.io/portfolio/projects/pawlife/#screenshots)

## Verification

- Lint, strict TypeScript, the existing Sumlume rules, the new life-rule tests and the production build passed. PawLife unit coverage exercised all 125 three-moment paths against both storm choices. PathLife rule coverage includes both career outcomes, state guards, the journal and reset.
- Chromium passed 126 route, viewport and theme combinations, 185 internal links and fragments, and 36 axe scans. Six additional scans of active game states at 320, 390 and 1440 CSS px in both themes found zero violations. The matrix covers keyboard and emulated mobile touch. Firefox and Playwright WebKit also passed smoke checks on all nine routes at 390 and 1440 px.
- In the in-app browser, I played the apprenticeship route through Age Up, extra shifts and the junior-job outcome. I played fetch before feeding and confirmed Bella’s tired response. Both resets restored the starting states. The recorded path exercises the alternative training route, and the recorded care sequence demonstrates successful fetch, grooming and comfort.
- The original games, CV files, homepage components, case-study components, and Sumlume and Physio-AI components were compared against production. The observed mobile PawLife scene clipping found in the first visual pass was corrected before the final captures and active layout checks.

## Performance

Both builds were served locally from production builds. Lighthouse 12.8.2 used three cold runs per build on mobile and one per build on desktop. Mobile used 150 ms simulated RTT and 4× CPU slowdown. Each run scored 100 for accessibility, best practices and SEO, and recorded zero CLS and total blocking time.

| Engineering Lab                | Production V4 | Lab V2 |
| ------------------------------ | ------------- | ------ |
| Mobile Lighthouse performance  | 97            | 98     |
| Mobile median LCP              | 2.36 s        | 2.26 s |
| Mobile cold transfer           | 267 kB        | 251 kB |
| Desktop Lighthouse performance | 100           | 100    |
| Desktop LCP                    | 0.46 s        | 0.49 s |
| Desktop cold transfer          | 299 kB        | 251 kB |

The V2 Lab route chunk is 10.78 kB of JavaScript and 5.92 kB of CSS gzipped. The larger interface is offset on initial load by the smaller game crops and on-demand reference imagery.
